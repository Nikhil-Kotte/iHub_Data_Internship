## 📖 Plot Explanations

### 1. Confusion Matrix (`confusion_matrix.png`)

**What it shows:**
- Rows = True labels (ground truth)
- Columns = Predicted labels
- Diagonal = Correct predictions
- Off-diagonal = Mistakes

**How to read:**
```
              Predicted
         Cat  Dog  Bird
True Cat  45   3    2    ← 45 cats correctly identified
     Dog   2  38    1    ← 2 dogs misclassified as cats
    Bird   1   0   47    ← Almost perfect bird detection
```

**Good model:**
- Dark colors along diagonal (high correct predictions)
- Light colors off-diagonal (few mistakes)

**Our results (COCO8):**
- mAP50: **73.92%** - Good detection at 50% IoU
- Most classes well-separated
- Some confusion between similar objects

---

### 2. F1-Confidence Curve (`BoxF1_curve.png`)

**What it shows:**
- X-axis: Confidence threshold (0.0 to 1.0)
- Y-axis: F1 score (harmonic mean of precision & recall)
- Each line = One object class

**F1 Score Formula:**
```
F1 = 2 × (Precision × Recall) / (Precision + Recall)
```

**How to interpret:**
- **Peak of curve** = Optimal confidence threshold
- **Higher peak** = Better class performance
- **Wide plateau** = Robust across thresholds

**Typical behavior:**
- Low confidence (0.0-0.3): High recall, low precision → Low F1
- Mid confidence (0.3-0.6): Balanced → **Peak F1**
- High confidence (0.7-1.0): High precision, low recall → F1 drops

**Our results:**
- Best F1: **~0.73** at confidence **~0.42**
- All classes @ 0.25: **F1 = 0.730**

**Use case:** Find optimal confidence threshold for deployment

---

### 3. Precision-Recall Curve (`BoxPR_curve.png`)

**What it shows:**
- X-axis: Recall (0 to 1)
- Y-axis: Precision (0 to 1)
- Area under curve = Average Precision (AP)

**Definitions:**
```
Precision = TP / (TP + FP)  # Of predictions, how many correct?
Recall = TP / (TP + FN)     # Of all objects, how many found?
```

**Perfect model:** Stays at top-right corner (Precision=1, Recall=1)

**How to interpret:**
- **Top-right region:** Best (high precision & recall)
- **Horizontal line at top:** Perfect precision
- **Steep drop:** Trade-off begins
- **Area Under Curve (mAP):** Overall quality metric

**Our results:**
- mAP50-95: **50.98%** - Solid performance
- Some classes near 100% AP (easy objects)
- Others lower (difficult/small objects)

**Use case:** Compare models, understand per-class performance

---

### 4. Precision Curve (`BoxP_curve.png`)

**What it shows:**
- X-axis: Confidence threshold
- Y-axis: Precision

**Typical behavior:**
- Low confidence: Many false positives → **Low precision**
- High confidence: Fewer predictions, mostly correct → **High precision**
- Curve usually **increases** with confidence

**How to read:**
```
At confidence 0.5:
- Precision = 0.90 means 90% of predictions are correct
- But you might miss some objects (lower recall)
```

**Our results:**
- Precision @ 0.25: **83.33%** - Good accuracy
- Increases to ~95%+ at higher thresholds

**Use case:** 
- Medical/safety applications: High precision needed (minimize false alarms)
- Set high confidence threshold

---

### 5. Recall Curve (`BoxR_curve.png`)

**What it shows:**
- X-axis: Confidence threshold
- Y-axis: Recall

**Typical behavior:**
- Low confidence: Detect almost everything → **High recall**
- High confidence: Miss many objects → **Low recall**
- Curve usually **decreases** with confidence

**How to read:**
```
At confidence 0.5:
- Recall = 0.80 means we found 80% of all objects
- But 20% are missed (higher threshold = miss more)
```

**Our results:**
- Recall @ 0.25: **65.00%** - Found 65% of objects
- Drops to ~20% at confidence 0.9

**Use case:**
- Search/surveillance: High recall needed (find everything)
- Set low confidence threshold

## 🎓 Key Metrics Explained

### 1. **mAP (mean Average Precision)**

**What:** Average of AP across all classes

**Variants:**
- **mAP50:** IoU threshold = 0.5 (easier, more lenient)
- **mAP50-95:** Average across IoU 0.5 to 0.95 (harder, COCO standard)

**Interpretation:**
- 0.0 - 0.3: Poor
- 0.3 - 0.5: Fair
- 0.5 - 0.7: Good (our detection: 0.51)
- 0.7 - 0.9: Very good (our detection @ IoU=0.5: 0.74)
- 0.9 - 1.0: Excellent

### 2. **IoU (Intersection over Union)**

**Formula:**
```
IoU = Area of Overlap / Area of Union
```

**Example:**
```
Ground Truth: [x=10, y=10, w=50, h=50]
Prediction:   [x=15, y=15, w=50, h=50]
IoU = ~0.68 (68% overlap)
```

**Thresholds:**
- IoU > 0.5: Good detection (True Positive)
- IoU < 0.5: Bad detection (False Positive)

### 3. **Precision vs Recall Trade-off**

**Precision:** Accuracy of positive predictions
- High precision → Few false alarms
- Use when: False positives are costly

**Recall:** Coverage of all actual objects
- High recall → Find everything
- Use when: Missing objects is costly

**Example:**
```
Medical screening:
- High recall needed (don't miss diseases)
- Accept some false positives for review

Spam detection:
- High precision needed (don't block real emails)
- Accept missing some spam
```

## 🎯 Practical Applications

### Use These Plots To:

1. **Choose Confidence Threshold**
   - F1 curve → Find peak
   - Balance precision & recall for your use case

2. **Identify Problem Classes**
   - Confusion matrix → Which classes confused?
   - PR curve → Which classes have low AP?

3. **Compare Models**
   - mAP → Overall quality
   - Speed metrics → Inference time
   - Choose best trade-off

4. **Debug Model Issues**
   - val_batch predictions → Visual inspection
   - Confusion matrix → Systematic errors
